# SK SYSTEM — Konfigurator 3D Hal

Prototyp demo interaktywnego konfiguratora hal stalowych dla [SK SYSTEM](https://sksystem.eu/).

## Stack

- React + Vite (Netlify)
- Three.js + React Three Fiber + Drei
- Zustand

## Uruchomienie

```bash
npm install
npm run dev
```

## Funkcje

- Podgląd 3D hali (dach dwuspadowy / jednospadowy)
- Parametry: długość, szerokość, wysokość, kąt dachu
- Kolory płyt warstwowych i dachu
- Konstrukcja stalowa, brama, drzwi, okna
- Geometria z wspólnymi wierzchołkami kalenicy i okapu
